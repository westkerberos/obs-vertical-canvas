The TikTok-native implementation in src/tiktok-native and the associated
Vertical Canvas session/output adapters are adapted from this project. The
adapted areas include request signing, frame signing, SEI metadata, desktop
and mobile device/session handling, room lifecycle, topic/game metadata,
QR login and LIVE safety support.

Local changes integrate those capabilities with OBS libobs, Qt, Vertical
Canvas output ownership and the WEST Gaming Aitum Multistream configuration
bridge. The Vertical Canvas fork does not run the original Python application
or an external media proxy.
